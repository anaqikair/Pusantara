## 1. System Overview

PUSANTARA is a differential-drive cultural heritage service robot built for
the VECTRA 2026 Creative Category competition. It combines autonomous
navigation (SLAM + Nav2), computer vision (YOLOv8 + AprilTag), speech
interaction (Whisper STT + Piper TTS + Qwen LLM), and interactive cultural
exhibition applications (food quiz, batik designer, keris AR demo, heritage
explainer) into a single ROS 2 workspace of 25 custom packages.

The robot operates on a Jetson Orin Nano running Ubuntu 22.04 with ROS 2
Humble. The software architecture is split into seven functional layers:

  Layer 1 — Hardware Drivers    : serial_bridge, bno055_driver, hls_lfcd_lds_driver, camera_node
  Layer 2 — Odometry & TF      : vectra_odometry, static TF publishers
  Layer 3 — Motion & Safety    : cmd_vel_bridge, motion_manager
  Layer 4 — SLAM & Navigation  : slam_toolbox, Nav2 stack (pusantara_navigation)
  Layer 5 — Perception         : vectra_yolo, apriltag_detector
  Layer 6 — Interaction & AI   : speech_to_text, tts_node, qwen_assistant, visitor_greeter, robot_face
  Layer 7 — Exhibition Apps    : food_quiz, batik_designer, keris_demo, heritage_explainer, malaysia_history_quiz
  Layer 8 — Administration     : pusantara_admin, pusantara_bringup

### 5.2 Typical Startup Sequence

```bash
# Terminal 1 — Core Robot
source /opt/ros/humble/setup.bash
source ~/vectra_ws/install/setup.bash
export ROS_DOMAIN_ID=1
ros2 launch pusantara_bringup robot.launch.py

# Terminal 2 — SLAM (mapping mode)
ros2 launch slam_toolbox online_async_launch.py \
  slam_params_file:=/home/orin_nano/vectra_ws/config/slam.yaml

# Terminal 3 — Navigation (with existing map)
ros2 launch pusantara_navigation navigation.launch.py \
  use_sim_time:=False autostart:=True \
  map:=$HOME/vectra_ws/maps/pusantara_map1.yaml \
  params_file:=$HOME/vectra_ws/src/pusantara_navigation/config/nav2_params.yaml

# Terminal 4 — cmd_vel bridge (needed when Nav2 drives the robot)
ros2 run cmd_vel_bridge cmd_vel_to_robot_command

# Terminal 5 — Perception
ros2 run camera_node webcam_pub
ros2 run vectra_yolo yolo_detector --ros-args -p debug:=true -p confidence_threshold:=0.6
ros2 run apriltag_detector apriltag_detector --ros-args -p show_ui:=true

# Terminal 6 — Exhibition applications (pick any)
ros2 run robot_face face_node
ros2 run visitor_greeter visitor_greeter
ros2 run heritage_explainer heritage_explainer
ros2 run food_quiz food_quiz
ros2 run batik_designer batik_designer
ros2 run keris_demo keris_demo

# Terminal 7 — Speech & AI
ros2 run tts_node tts_node
ros2 run speech_to_text stt_node
ros2 run qwen_assistant qwen_node

# Terminal 8 — Admin Console
ros2 run pusantara_admin admin_console
```

### 5.3 Nodes Launched by robot.launch.py

The bringup launch file starts 6 items:

  1. hlds_laser_publisher (LiDAR, port: CP2102 by-id)
  2. imu_node (BNO055, I2C)
  3. motion_manager (safety layer)
  4. serial_bridge (bridge_node, FTDI)
  5. vectra_odometry (odometry.launch.py include)
  6. static_transform_publisher (base_link → laser: x=0.135, z=0.60)

### 5.4 Nodes Launched by navigation.launch.py

  1. map_server (nav2_map_server)
  2. amcl (nav2_amcl)
  3. planner_server (nav2_planner — NavfnPlanner)
  4. controller_server (nav2_controller — DWBLocalPlanner, remaps cmd_vel → /cmd_vel)
  5. bt_navigator (nav2_bt_navigator)
  6. behavior_server (nav2_behaviors — Spin, BackUp, Wait)
  7. lifecycle_manager_navigation (autostart: true)

### 6.7 Detection String Formats

**YOLO /yolo/detections format:**
  `person,<conf>,<center_x>,<center_y>,<width>,<height>`
  Multiple detections separated by `;`

**AprilTag /apriltag/detections format (JSON):**
  ```json
  {
    "id": 2,
    "center_x": 320, "center_y": 240,
    "width": 45, "height": 45,
    "area": 2025,
    "frame_width": 640, "frame_height": 480,
    "normalized_x": 0.5, "normalized_y": 0.5,
    "timestamp": 1719811234.567
  }
  ```

### 7.6 motion_manager

| Parameter         | Type    | Default | Description                                  |
|-------------------|---------|---------|----------------------------------------------|
| mode              | string  | "SAFE"  | Mode: SAFE (stop), ASSIST (slow), OVERRIDE   |
| stop_distance     | float   | 0.15    | Distance to hard-stop (m)                    |
| warning_distance  | float   | 0.50    | Distance to slow down in ASSIST mode (m)     |
| front_angle       | float   | 30.0    | Front cone half-angle (degrees)              |

  Safety modes:
    SAFE     — Stops robot if obstacle < stop_distance

## 12. Motor Controller Firmware (Arduino / PRIZM)

The PRIZM controller runs an Arduino sketch that handles:

### Motor Control
  - Motor 1 = RIGHT wheel
  - Motor 2 = LEFT wheel (power inverted: `prizm.setMotorPower(2, -leftSpeed)`)
  - Speed range: -100 to +100
  - Commands: W (forward 50), S (reverse 50), A (turn left), D (turn right),
    X (stop), M,<right>,<left> (differential drive)

### Encoder Publishing
  - Published at 100 ms intervals (10 Hz)
  - Format: `E,<left_ticks>,<right_ticks>`
  - Left encoder = `prizm.readEncoderCount(2)` (direct)
  - Right encoder = `-prizm.readEncoderCount(1)` (negated for convention)

### Gripper / Arm Servos
  - Servo 1: Left arm (0–180°)
  - Servo 2: Right arm (0–180°, mirrored)
  - Servo 3: Gripper (0 = closed, 180 = open)
  - Sequences: TAKEIN (pick up), TAKEOUT (place down), OPEN, CLOSE,
    FORWARD (arm forward), BACK (arm back)

### Baud Rate
  - 115200 (matching serial_bridge)

───────────────────────────────────────────────────────────────────────────────

## 13. Serial Communication Protocol

### Direction: Jetson → PRIZM (TX)

| Command           | Format                  | Description                               |
|-------------------|-------------------------|-------------------------------------------|
| Stop              | `X\n`                   | Immediately stop both motors              |
| Differential Drive | `M,<right>,<left>\n`   | Set motor powers (-100 to 100)            |
| Forward           | `W\n`                   | Both motors forward at 50                 |
| Reverse           | `S\n`                   | Both motors reverse at 50                 |
| Turn Left         | `A\n`                   | Spin left (right +50, left -50)           |
| Turn Right        | `D\n`                   | Spin right (right -50, left +50)          |
| Gripper Open      | `OPEN\n`                | Open gripper servo                        |
| Gripper Close     | `CLOSE\n`               | Close gripper servo                       |
| Arm Forward       | `FORWARD\n`             | Rotate arm to forward position            |
| Arm Back          | `BACK\n`                | Rotate arm to back position               |
| Pick Up           | `TAKEIN\n`              | Full pick-up sequence                     |
| Place Down        | `TAKEOUT\n`             | Full place-down sequence                  |

### Direction: PRIZM → Jetson (RX)

| Packet            | Format                  | Description                               |
|-------------------|-------------------------|-------------------------------------------|
| Encoder           | `E,<left>,<right>\n`    | Cumulative encoder tick counts (10 Hz)    |

### Motor Command Pipeline

```
Nav2 controller    →  /cmd_vel (Twist)
                        ↓
              cmd_vel_to_robot_command  (differential drive math)
                        ↓
                   /robot_command (String: "M,right,left")
                        ↓
              motion_manager  (LiDAR safety check)
                        ↓
                   /safe_robot_command (String)
                        ↓
              serial_bridge  (USB serial write)
                        ↓
                   PRIZM Arduino  (motor power set)
```
